# Test scripts

Python scripts for the subset described in `PYTHON.md` at the root of the
repository. They are **valid Python 3**: CPython is the oracle.

- A script that only asserts must exit with status 0.
- A script that prints has its expected output in `<name>.out`, generated with
  CPython.
- `deviations/` holds scripts that rely on a documented difference from
  CPython (32-bit integers, execution limits). They are not run under CPython.

Check everything with CPython (and regenerate the `.out` files with
`--update`):

    python3 tools/cpython_check.py [--update] [path ...]

| Directory | Content |
|---|---|
| `regressions/` | small scripts for bugs found along the way |
| `language/` | functions, closures, recursion, control flow, operators, iteration, comprehensions, exceptions, compiler limits (`limits.py` is generated by `tools/gen_limits.py`) |
| `builtins/` | `str`, formatting, `list` / `tuple`, `dict`, `math` and the numeric builtins |
| `errors/` | wrong arguments to builtins and methods (exception types only) |
| `perf/` | benchmarks (nbody, fannkuch, binarytrees, nsieve) with small sizes |
| `deviations/` | see above |
